# ChatNow

ChatNow is a Nintendo 3DS chat client. Download `ChatNow.cia` from the
[v1.0.0 release](https://github.com/jamesrhg/chatnow/releases/tag/v1.0.0)
and install it with a CIA installer on a homebrew-enabled console.

This repository distributes the installable app only. It does not publish
client or server source code.

**Connection disclaimer:** This build uses TLS encryption but does not verify
HTTPS or WebSocket server certificates or hostnames. A network intermediary
could impersonate the service. Use it only on networks you trust.
